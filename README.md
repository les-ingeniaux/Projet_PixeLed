# Projet PixeLed

Vous trouverez dans le dossier code les fichiers à utiliser pour personnaliser votre PixeLed.
Vous pouvez les télécharger et les transférer sur votre Raspberry Pi Pico W en utilisant Thonny: une fois cela fait, vous pourrez librement éditer le fichier main.py pour y ajouter votre code.

Bon courage !
